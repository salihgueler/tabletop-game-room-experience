# Flutter Workshop Workspace

This Flutter project is the client workspace used throughout the workshop.
Module 01 creates this app's independent `backend/` folder. Later modules evolve
`backend/aws-blocks/index.ts`; the Flutter UI remains a thin typed client.

The workshop backend is not shared with `../../tabletop-flutter/` or
`../../tabletop-app/`.

Run `flutter pub get`, then begin at [`../01-scaffold/README.md`](../01-scaffold/README.md).
